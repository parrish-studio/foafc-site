## Site Map
The prototype contains the following pages with real-(ish) copy and layout.

| Page | What's On It (or planned) |
|---|---|
| Home | Hero with call-to-action, live trail status banner, feature highlights (four-season activities, dog-friendly, volunteer-run), weather widget, donate prompt |
| Trails | Embedded Google map to trail head, view/download trails map. All 12 trails with distance/difficulty/description, trail etiquette rules, safety guidelines |
| About | Mission and vision statements, board members, trail system history timeline, current projects and community impact |
| Blog | Featured post with image, chronological feed, email newsletter signup sidebar. Cross-linked to Facebook/Insta. |
| Events | Calendar view, upcoming events list with RSVP, event details. Cross-linked to Facebook |
| Donate | Day pass ($10), season pass ($150), custom amount form, 501(c)(3) tax-deductible notice |
| Trail Desk (internal only) | Blog post composer and event manager for board members to publish news and schedule events |
| Content Studio (internal only) | Rich content editor with image uploads and social media cross-publishing |

Global elements: top navigation, mobile hamburger menu, footer with org info, email signup, and social links.
