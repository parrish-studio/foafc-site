# Logo Usage Guide
_Copied from the Canva doc "Logo Usage Guide." Friends of a Fierce Chase, Monson, Maine._

## Variants and usage
- **Color primary (circle badge):** forest green T-Rex on skis on a sage background, ringed by gold "FRIENDS OF A FIERCE CHASE" text. Use for hero sections, the About page, prominent display.
- **Color icon (small circle):** simplified badge. Use for favicons, mobile nav, social avatars, tight spaces.
- **Color horizontal (badge + text):** badge left of the name. Use for desktop nav bars and site headers.
- **Color wordmark (text only):** name in the primary color. Use for compact spaces and email signatures.
- **Cream/white variants:** for dark backgrounds, footers, forest-green overlays.
- **Black variant:** print, merchandise, monochrome, embroidery.

The Drive set also includes **vertical** lockups and **Green, Gold, and Navy** colorways for every variant (see `asset-index.md`).

## Brand colors
- Forest green — primary logo element
- Amber/gold — logo text, accents
- Cream — backgrounds, alternate logo color
- Sage — primary logo background

## General rules
Keep clear space around the logo. Do not distort, stretch, or alter it.
