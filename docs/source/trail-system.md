# Trail System Information
_Copied from the Canva doc "Trail System Information" (https://www.canva.com/d/PxvWD1jbKJIXNTy)._

The full trail list, rules and safety notice are kept as structured data in
[`packages/module-trails/data/trails.json`](../../packages/module-trails/data/trails.json), which is the copy to edit.

Summary: 12 named trails, 8.3+ miles. Meandering Moose Loop is the longest (1.91 mi). Snake Trail is one way only. Craig's Orchard, Craig's Trail, Snake and Arthur's Loop are no-skate.

Data check: Wolf Chase Loop shows 1.48 km in the source, the same as Fierce Fisher; 0.69 mi is about 1.11 km.
