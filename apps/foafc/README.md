# apps/foafc

The Friends of A Fierce Chase site. An **Astro** site with React islands (see `docs/decisions/0002-astro-with-react-islands.md`). Not scaffolded yet.

This app holds FOAFC-specific content, pages, routing and config, and consumes `@parrish-studio/tokens` and the `module-*` packages. Keep it thin; anything reusable belongs in a package.
