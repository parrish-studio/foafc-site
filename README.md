# foafc-site

Website for [Friends of A Fierce Chase](https://friendsofafiercechase.org), a volunteer-run cross-country ski trail system in Monson, Maine.

Also the first build of the Parrish Studio platform: a set of reusable packages (design tokens, feature modules, admin tools) for small-business sites.

## Layout

| Path | What |
|---|---|
| `apps/foafc` | The FOAFC site (framework TBD) |
| `packages/tokens` | Design tokens as CSS custom properties |
| `packages/module-trails` | Trails module: schema, data, UI |
| `docs/` | Project brief, source material, decision records |

## Getting started

```sh
pnpm install
```

App scripts arrive once the framework is chosen (see `docs/decisions/`).
